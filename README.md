# KabadiAI

Photograph old electronics and learn what they are, which are hazardous, what they are roughly worth, and where to take them. Built for the Bharat Builds Tour: Environmental Hacks (Waste and Energy track).

Status: Day 1 in progress. Backend scan endpoint (AWS SAM, API Gateway, Lambda, Amazon Bedrock).

AI coding tools used: Claude, Antigravity.
